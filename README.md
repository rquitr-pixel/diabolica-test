# Diabolica – wersja testowa v33

To publiczne repozytorium zawiera wyłącznie gotowy build Windows gry **Diabolica** (wersja v33) do testów.

## Jak uruchomić

1. Pobierz plik `Diabolica_Win64_v33.zip` z [wydania v33](https://github.com/rquitr-pixel/diabolica-test/releases/tag/v33).
2. Rozpakuj archiwum.
3. Uruchom `Diabolica/Diabolica.exe`.

**Wymagania:** Windows 64-bit.

## Co nowego w v33

- Techniki broni pod klawiszami **Z** i **V**: 16 technik (po dwie na szkołę broni), rangi I–III. Sloty w HUD pokazują odnowienie.
- Pięciu mistrzów w wiosce uczy technik za złoto: Mistrz Miecza Wacław, Mistrz Bolesław, Pradawny Mnich Tadeusz, Mistrzyni Cienia Jagna i Generał Dorthan.
- 6 broni miotanych z magazynkiem, który odnawia się po jednej sztuce (HUD pokazuje np. 3/6). Noże i sztylety wbijają się w ziemię i trzeba je podnieść.
- Dwa zestawy broni: **X** przełącza zestaw A/B, **R** zmienia broń w aktywnym zestawie.
