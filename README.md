# Diabolica – wersja testowa v32

To publiczne repozytorium zawiera wyłącznie gotowy build Windows gry **Diabolica** (wersja v32) do testów.

## Jak uruchomić

1. Pobierz plik `Diabolica_Win64_v32.zip` z [wydania v32](https://github.com/rquitr-pixel/diabolica-test/releases/tag/v32).
2. Rozpakuj archiwum.
3. Uruchom `Diabolica/Diabolica.exe`.

**Wymagania:** Windows 64-bit.

## Co nowego w v32

- Każdy potwór ma własny zestaw ataków, własne znaczniki na ziemi i własny sposób poruszania się.
- Każdy boss ma unikalne ataki, a każda kolejna faza dokłada nowe. Generał Morvath w Zgniłym Lochu wiruje z halabardą po arenie („Wir ostrza”).
- Nowe kształty znaczników: pierścień, sierp, krzyż, runa, cień i smuga ostrza.
- Kosa bojowa przyciąga. Panel szczegółów w sklepach mieści pełny opis każdej zbroi.
