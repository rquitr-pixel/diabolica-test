# Diabolica – wersja testowa v30

To publiczne repozytorium zawiera wyłącznie gotowy build Windows gry **Diabolica** (wersja v30) do testów.

## Jak uruchomić

1. Pobierz plik `Diabolica_Win64_v30.zip` z [wydania v30](https://github.com/rquitr-pixel/diabolica-test/releases/tag/v30).
2. Rozpakuj archiwum.
3. Uruchom `Diabolica.exe`.

**Wymagania:** Windows 64-bit.
